Create and run a REST API server on port 8000 that performs signal processing operations. The server must be implemented in a file named `/app/server.py` and handle dynamic signal inputs (random waveforms generated by tests).

## Required Endpoints

### 1. POST /signal/fft
Compute Fast Fourier Transform of a signal.

**Request:**
```json
{
  "signal": [float, ...],
  "sample_rate": float
}
```

**Response:**
```json
{
  "frequencies": [float, ...],
  "magnitudes": [float, ...],
  "phases": [float, ...],
  "peak_frequency": float
}
```

**Requirements:**
- Return only positive frequencies (first half of FFT spectrum)
- `frequencies`: frequency values in Hz for each bin
- `magnitudes`: absolute magnitude of FFT at each frequency
- `phases`: phase angle in radians (range: -π to π) at each frequency
- `peak_frequency`: frequency with the highest magnitude (excluding DC component at 0 Hz)
- Return 400 if signal is empty or sample_rate <= 0

### 2. POST /signal/filter
Apply a digital Butterworth filter to a signal.

**Request:**
```json
{
  "signal": [float, ...],
  "filter_type": "lowpass" | "highpass" | "bandpass",
  "cutoff": float | [float, float],
  "order": int,
  "sample_rate": float
}
```

**Response:**
```json
{
  "filtered_signal": [float, ...],
  "filter_order": int
}
```

**Requirements:**
- `filter_type`: "lowpass", "highpass", or "bandpass"
- `cutoff`: single float for lowpass/highpass, array of two floats [low, high] for bandpass
- `filter_order`: must match the requested order from input
- `filtered_signal`: must have same length as input signal
- Use Butterworth filter design (scipy.signal.butter recommended)
- Return 400 if signal is empty, sample_rate <= 0, or cutoff is missing

### 3. POST /signal/convolution
Compute the convolution of two signals.

**Request:**
```json
{
  "signal1": [float, ...],
  "signal2": [float, ...]
}
```

**Response:**
```json
{
  "result": [float, ...],
  "length": int
}
```

**Requirements:**
- Compute full convolution (not 'same' or 'valid' mode)
- `length` must equal len(signal1) + len(signal2) - 1
- `result` array must have length equal to `length` field
- Return 400 if either signal is empty

### 4. POST /signal/spectrogram
Generate a spectrogram using Short-Time Fourier Transform (STFT).

**Request:**
```json
{
  "signal": [float, ...],
  "window_size": int,
  "hop_size": int,
  "sample_rate": float
}
```

**Response:**
```json
{
  "time_bins": [float, ...],
  "frequency_bins": [float, ...],
  "magnitudes": [[float, ...], ...]
}
```

**Requirements:**
- Use STFT with overlapping windows
- `hop_size` determines the overlap between consecutive windows
- `time_bins`: time values for each window center
- `frequency_bins`: frequency values (positive frequencies only)
- `magnitudes`: 2D array where magnitudes[freq_idx][time_idx] is the magnitude
- Return 400 if signal is empty, window_size > signal length, or sample_rate <= 0

## Implementation Guidelines

1. **Server Framework**: Use Flask or FastAPI
2. **Signal Processing**: Use numpy and scipy for computations
3. **Error Handling**: Return appropriate HTTP status codes (400 for validation errors)
4. **Efficiency**: Handle signals up to 10,000 samples
5. **Numerical Precision**: Use standard floating-point precision (no special rounding required)

## Validation Rules

- Empty signals should return 400
- Invalid sample rates (≤ 0) should return 400
- Missing required parameters should return 400
- Window size larger than signal length should return 400
